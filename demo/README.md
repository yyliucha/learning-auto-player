# 本地演示

`index.html` 是一个**模拟在线学习平台**的演示页，无需真实账号即可体验脚本全部功能。它模拟了真实平台的三个特征：

1. **切标签页暂停视频**（监听 `visibilitychange`）
2. **每集结束弹"课程评价"弹窗**（取消/提交评价）
3. **没有自动连播入口**（需点章节列表切换，返回按钮是图标按钮）

## 运行方式（二选一）

### 方式 1：直接打开（控制台粘贴脚本）

双击 `index.html`（file:// 打开即可）→ F12 → Console → 粘贴 `auto-learn.user.js` 全部内容 → 回车。

### 方式 2：本地 HTTP 服务（配合 Tampermonkey）

```bash
cd demo
python -m http.server 8000     # 或 npx http-server
```

浏览器打开 http://localhost:8000（`*://*/*` 匹配，Tampermonkey 自动注入脚本）。

## 演示步骤

1. 加载脚本（方式 1 或 2）
2. 点页面上的 **【一键配置演示规则】**（会把演示规则存到本地 localStorage）
3. 点击右下角徽标，切到 **🚀 自动遍历**（蓝青色）
4. 观察自动流程：
   - 列表页自动进入"演示课程 A"（跳过带"已完成"的课程 C）
   - 每个约 5~10 秒的视频播完 → 自动关掉"课程评价"弹窗 → 自动点下一章节
   - 课程 A 播完 → 自动点"← 返回" → 列表 → 自动进课程 B → 全部完成 🎉
5. 播放中途切到别的标签页 10 秒再回来：视频没被暂停（防暂停生效）

## 说明

- 演示视频来自 MDN / W3Schools 的公开示例视频（flower.mp4 ≈5s，mov_bbb.mp4 ≈10s），需要联网
- 演示规则存在 localStorage（`autoLearn.rule.localhost`），只在本机生效
- 不用演示规则也行：页面有"下一课 ▸"按钮，脚本的**通用模式**（文字按钮匹配）也能演示自动连播
